# Frontmatter stores only what the graph cannot derive

A Note's frontmatter carries `kind`, `domain`, `requires`, `status`, `reviewed_by`, `created`, `updated`, `aliases`, `tags` — and nothing else. Anything computable from the graph is computed, never declared: no `level`, no `difficulty`, no `depth`, no `link_count`, no `is_floor`, no `is_hub`. Directory structure is flat at depth 1 for the same reason, rather than nesting by graph depth. `requires` is the one apparent exception and is not one: it *is* the graph, not a fact derived from it.

The reverse direction follows. A Note declares what it requires; the `## Required by` and `## Builds on` sections are generated by script from the inverted `requires` map, and agents write Edges in one direction only, ever.

## Consequences

A reader will wonder why a teaching wiki has no `level` or `difficulty` field. It has no need of one: the Floor is `requires: []`, the Terminal Node is in-degree zero, a hub is high in-degree, and a learning sequence is a topological sort. Declaring any of these would create a second answer that can disagree with the first, and the disagreement is always silent.

This is the lesson the reference wiki at `C:\Code\el_nino\wiki` teaches by counterexample. Every drift it accumulated was a declared fact that reality moved away from: 20 declared domains against 17 real directories, a four-value `status` enum whose pages were all on one value, and a hand-maintained statistics block wrong about its own file count. None of those are failures of diligence. They are what declaring derivable facts does over time.

It also costs the reference wiki's hand-written bidirectional cross-linking, which its own journal records repairing one missed edge at a time — unbounded manual labour that degrades as the graph grows. Generating the reverse direction removes the class of error entirely.

The cost is that the frontmatter alone cannot tell you where a Note sits. You have to run the script. That is the intended trade: one answer, computed, over two answers, one of them stale.
