# Modules are the prerequisite closure of one Terminal Node, not a syllabus

A Module's content is defined by naming a single Terminal Node and expanding downwards through prerequisite Edges until every path reaches the Floor. The first Module's Terminal Node is the derivative, with an 8th-grade Floor. We did not define Modules as a syllabus of topics to cover.

## Considered Options

**Syllabus-anchored**: enumerate the topics of pre-calculus (functions, trigonometry, sequences, conics, logarithms, vectors…) and write a Note for each.

**Target-anchored** (chosen): name one Terminal Node and derive the Node set as its Prerequisite Closure.

## Consequences

Expect a reader to be surprised by absences. A wiki whose first Module is "pre-calculus" but which contains no Note on conic sections looks incomplete; it is not. Conics are absent because the derivative does not require them. Absence is a statement about Edges, never an oversight to be filled in.

Every Node has a defensible reason to exist — a path to the Terminal Node — which is the primary defence against agents generating plausible but purposeless content at scale.

Graph population gains a computable stopping criterion: expansion terminates when no Node has an unexplained prerequisite above the Floor. A syllabus-anchored graph can only stop when coverage "feels" complete, which no agent can evaluate and which therefore grows without bound.

Later Modules anchor on new Terminal Nodes and reuse the Prerequisite Closure that already exists, so breadth is deferred rather than lost.
